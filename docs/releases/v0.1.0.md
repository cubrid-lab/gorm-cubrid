## v0.1.0 (2026-03-14)

Initial GORM dialect release for CUBRID.

### Compatibility

- The tagged Go module declares Go 1.21 and GORM v1.25 dependencies. The original notes describe CUBRID 11.2 or newer; this is a declared target, not proof of full live-database compatibility.
- The original validation described 38 unit tests that did not require a real CUBRID server. Live broker interoperability was not established by those tests.
- This description correction does not modify the historical Go module import path or create a new module version.

### Features

- Add GORM constructors and the `gorm.Dialector` implementation for CUBRID SQL by @yeongseon
- Implement CUBRID-oriented schema inspection and migration operations by @yeongseon
- Support CUBRID-specific SQL quoting, binding and type mapping in GORM by @yeongseon
